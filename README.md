# Modern PHP CRUD with Tailwind CSS, Chart.js, SweetAlert2

This project is a simple starter demonstrating:

* Authentication (login/register/logout)
* CRUD for a `records` table
* Sidebar layout with Tailwind CSS
* Charts on the dashboard using Chart.js
* Modern alerts (SweetAlert2) on save, update, delete, logout
* MySQL (PDO) database connection

## Quick Start

1. Import `schema.sql` into your MySQL server.
2. Copy `config/database.example.php` to `config/database.php` and edit with your DB credentials.
3. Serve the project with a local PHP server:

    ```bash
    php -S localhost:8000
    ```
